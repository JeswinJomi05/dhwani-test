# PgBee — Stay Hub

A responsive Next.js and React frontend recreated from `1.png`.

## Run locally

```sh
npm install
npm run dev
```

Open http://localhost:3000. To build for production, run `npm run build` then `npm start`.

The page includes a photo viewer, wishlist, currency selector, booking and group-stay forms, a contact form, and a linked location map. Forms are frontend previews: they do not send messages, make reservations, or process payments.

The supplied brand logos are used directly. Property photos and the static map are extracted from the provided reference image because original property assets were not supplied. Poppins is served locally with Fontsource.
